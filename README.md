## About Me

I build **scalable backend systems** and **high-performance web applications** with Laravel. I care about clean code, fast queries, and architecture that holds up at scale — not just CRUD.

> *"Code is like humor. When you have to explain it, it's bad."* — Cory House

- **4+ years** shipping real, production Laravel applications
- **15+ projects** — B2B SaaS, HRIS, LMS, booking systems, marketplaces
- Deep with **REST APIs · MySQL · Redis · Queues · AWS S3 · WebSockets**
- Currently exploring **AI integrations** and **real-time notification systems**
